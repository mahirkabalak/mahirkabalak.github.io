# mahirkabalak.github.io

Bu depo, GitHub Pages kullanıcı sitesinin kökünü yayınlar:
https://mahirkabalak.github.io/

Ayetlerden Dersler proje sitesi ayrı depodadır ve şu adreste kalır:
https://mahirkabalak.github.io/ayetlerden-dersler/

Android uygulamasının (Trusted Web Activity) siteyi tam ekran açabilmesi için Digital Asset Links dosyası kökte olmalıdır:

https://mahirkabalak.github.io/.well-known/assetlinks.json

Bu dosyadaki parmak izi şu an yükleme (upload) anahtarına aittir. Play Console'da Play Uygulama İmzalama açıldıktan sonra "Uygulama imzalama anahtarı" SHA-256 değeri de aynı JSON dizisine eklenmelidir.
